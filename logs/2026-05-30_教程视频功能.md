## 功能概述

本次更新实现了完整的教程视频管理功能，包括：

1. **Bilibili视频集成**

2. **视频管理后台**

   - 支持本地图片上传作为缩略图
   - 包含图片预览功能
   - 编辑时可替换或删除现有缩略图

4. **教程页面优化**
   - 从数据库读取视频列表
   - 分类占位图标（解决Bilibili防盗链问题）
   - 删除新手入门模块

## 数据库表结构

```sql
CREATE TABLE tutorial_videos (
    id INT PRIMARY KEY AUTO_INCREMENT,
    bvid VARCHAR(50) NOT NULL COMMENT 'BV号',
    title VARCHAR(200) NOT NULL COMMENT '视频标题',
    description TEXT COMMENT '视频描述',
    thumbnail_url VARCHAR(300) COMMENT '缩略图',
    category ENUM('maps','vehicles','weakspots') COMMENT '分类',
    view_count INT DEFAULT 0 COMMENT '播放次数',
    likes INT DEFAULT 0 COMMENT '点赞数',
    author VARCHAR(50) COMMENT 'UP主',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## 功能特点

1. **权限控制**：仅管理员和小管理可管理视频
2. **图片上传**：支持本地图片上传，自动保存到 `upload/video/` 目录
3. **错误处理**：图片加载失败时显示分类占位图标
4. **响应式设计**：适配各种屏幕尺寸
5. **深色主题**：与论坛整体风格一致

## 使用说明

1. **执行数据库SQL**：在MySQL中执行 `tutorial_videos.sql` 创建表
2. **访问管理页面**：登录管理员账号，在教程页面点击"管理视频"
3. **添加视频**：填写BV号和标题，可上传缩略图
4. **观看视频**：在教程页面点击视频卡片即可播放

## 注意事项

- 缩略图使用本地图片，避免Bilibili防盗链问题
- 上传的图片保存在 `webapps/myhomework/upload/video/` 目录
- 视频播放器使用官方iframe，依赖网络访问Bilibili
