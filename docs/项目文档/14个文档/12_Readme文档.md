## 快速开始

### 环境要求

- JDK 8 或更高版本
- Tomcat 8.5 或更高版本
- MySQL 5.7 或更高版本
- 浏览器：Chrome 80+, Firefox 75+, Edge 80+, Safari 13+

### 安装与运行

```bash
# 1. 克隆仓库
git clone https://github.com/example/war-thunder-forum.git

# 2. 进入目录
cd war-thunder-forum

# 3. 配置数据库
# 创建数据库：CREATE DATABASE warthunder_forum CHARACTER SET utf8mb4;
# 执行 database/ 目录下的SQL文件

# 4. 配置连接
# 修改 db/DBHelper.java 中的数据库连接信息

# 5. 部署到Tomcat
# 将项目打包为WAR文件，部署到Tomcat的webapps目录

# 6. 启动Tomcat
# 访问 http://localhost:8080/war-thunder-forum
```

打开 `http://localhost:8080/war-thunder-forum`，注册账号后即可使用。

> 📝 **快速开始必须可执行**：写完后自己从头跑一遍，确保3步内能运行起来。

## 核心特性

### 用户系统

- **用户注册登录**：完整的用户认证系统，支持邮箱注册
- **个人中心**：管理个人信息、修改头像和密码
- **权限管理**：管理员、版主、普通用户三种角色

### 论坛功能

- **帖子浏览**：查看论坛帖子列表，按时间排序
- **发布帖子**：支持文本内容和最多6张图片上传
- **评论系统**：支持评论和回复功能
- **帖子管理**：编辑和删除自己发布的帖子

### 教程中心

- **视频教程**：集成Bilibili视频，支持分类浏览
- **图文教程**：发布和浏览图文攻略
- **分类筛选**：按地图解析、载具测评、车辆弱点分类

### 搜索功能

- **帖子搜索**：输入关键词快速搜索相关帖子
- **用户搜索**：管理员可以搜索和管理用户账号

### 管理员功能

- **用户管理**：查看、编辑、删除用户账号
- **内容管理**：管理帖子和评论
- **视频管理**：添加、编辑、删除视频教程

> 📝 **写法提示**：每个特性用 **加粗关键词** 开头，后跟一句话说明用户能得到什么价值。不要写"使用了XXX技术"，要写"用户可以XXX"。
