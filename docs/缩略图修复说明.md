# 缩略图显示问题修复说明

## 问题
Bilibili 视频缩略图无法正常显示，原因是：
1. Bilibili 有防盗链机制，直接引用图片会被拒绝
2. 图片加载失败时没有备用方案
3. 部分视频没有设置缩略图

## 修复方案

### 1. 添加了缩略图获取函数
文件：`tutorial.jsp` 和 `adminVideos.jsp`
- `getThumbnailUrl(VideoModel video)` 函数
- 根据视频分类返回对应的占位图标

### 2. 按分类显示不同的图标
- 🗺️ 地图解析
- ⚔️ 载具测评
- 🎯 车辆弱点
- 🎬 默认视频图标

### 3. 添加了错误处理
- 使用 `onerror` 属性处理图片加载失败
- 图片加载失败时显示备用的 SVG 图标
- 防止页面出现破损的图片

### 4. 使用内联 SVG
- 不依赖外部图片服务
- 加载速度快，无跨域问题
- 保持深色主题风格

## 使用建议

### 添加视频时的缩略图选择
1. **可选**：手动复制 Bilibili 视频封面图片地址
2. **推荐**：留空，系统会自动显示分类图标
3. **注意**：Bilibili 图片可能因防盗链无法正常显示

### 缩略图显示优先级
1. 首先显示用户设置的缩略图 URL
2. 如果加载失败，显示备用 SVG 图标
3. 如果没有设置，显示分类对应图标

## 修改的文件
- `src/main/webapp/tutorial.jsp` - 教程页面
- `src/main/webapp/adminVideos.jsp` - 视频管理页面
