# 项目开发日志

## War Thunder 社区论坛系统

> 📝 **开发日志按时间顺序记录每个版本的实际开发工作。**

---

## v1.0 — 2026-05-26 — 基础论坛功能

完成了项目的基础搭建和核心功能开发。这是一个从零开始的项目，搭建了完整的 Java Web 项目结构，设计了数据库表结构，实现了用户注册登录功能，创建了论坛首页和帖子详情页。本阶段的主要工作是建立项目的整体框架，为后续功能开发奠定基础。遇到的主要挑战是数据库连接配置和中文乱码问题，通过设置 UTF-8 编码解决。

**功能增强**：完善了用户权限功能（管理员、版主、普通用户三级权限），版主可删除普通用户帖子但不能删除管理员帖子；发布帖子支持最多6张图片上传；论坛首页显示帖子内容预览（最多两行）和最多三张图片缩略图，点击可放大查看；评论功能支持显示用户头像，用户可删除自己的评论；新增用户管理页面，管理员可管理用户账号和权限。

---

## v2.0 — 2026-05-27 — 图片功能和战绩查询

在基础论坛功能上增加了图片上传功能，用户发布帖子时可以上传最多 6 张图片。同时集成了外部战绩查询服务，添加了 War Thunder 官网和 statshark.net 的链接。本阶段的重点是文件上传功能的实现，使用了 Servlet API 进行文件处理。

---

## v3.0 — 2026-05-28 — 搜索功能

实现了帖子的全文搜索功能和用户搜索功能（管理员专用）。在帖子列表页面添加了搜索框，用户可以输入关键词搜索帖子。管理员可以在用户管理页面搜索用户账号。搜索功能使用 MySQL 的 LIKE 查询实现，支持模糊匹配。

---

## v4.0 — 2026-05-30 — 教程视频功能

本阶段是项目的重要扩展，添加了完整的教程视频功能。主要工作包括：集成 Bilibili 视频嵌入播放功能，使用 iframe 在网页中播放 B 站视频；实现了视频分类管理功能，支持地图解析、载具测评、车辆弱点三个分类；创建了视频管理后台页面，管理员可以添加、编辑、删除视频；实现了视频缩略图上传功能，提升视频列表的视觉效果。同时创建了视频相关的数据表和控制器，完善了项目的数据模型。

---

## v5.0 — 2026-05-31 — 教程功能完善

这是项目的重要迭代，完成了教程中心功能的全面优化。添加了"全部内容"分类卡片，用户可以一键查看所有教程；在每个分类页面同时显示视频和文章，实现了内容的整合展示；分类卡片上显示真实的内容数量（文章数和视频数），提升用户体验；在视频教程区域添加了"发布视频"按钮，与教程文章保持一致的发布入口；优化了页面布局和交互设计，修改了 showCategory 函数以正确处理内容切换。本阶段还完成了完整的项目文档，包括 README、项目建议书、需求规格说明书、项目计划书等，并生成了详细的 Git 提交历史记录。

---

## v6.0 — 2026-06-04 — 功能完善与Bug修复

本次迭代主要完善了用户登录注册功能，增强了管理员管理功能，并修复了多个Bug。登录功能增加了密码错误提示和用户不存在提示，提升了用户体验；注册功能增加了邮箱已存在检测，防止重复注册；新增了找回密码功能，提供联系管理员的联系方式；管理员功能增强，支持查看用户密码（仅管理员可见）；用户管理页面添加了返回按钮，方便操作；修复了论坛按钮跳转错误的问题；新增了findUserByEmail()数据访问方法，支持按邮箱查询用户信息。整体提升了系统的用户友好性和稳定性。

---

## v7.0 — 2026-06-11 — 内容审核功能

本次迭代实现了完整的内容审核工作流，增强了内容管理的安全性和可控性。为帖子、教程文章、视频表添加了审核状态字段，实现了基于用户角色的差异化审核规则：普通用户发布的所有内容均需审核，版主发布的帖子和文章可直接通过但视频仍需审核，管理员发布的所有内容直接通过。创建了专门的审核管理页面，支持审核通过和拒绝操作，并在用户个人中心显示内容审核状态。同时添加了视频发布功能入口，完善了教程中心的功能。
