# 视频缩略图上传功能说明

## 修改内容

### 1. VideoController.java
- 添加 `@MultipartConfig` 注解，支持文件上传
- 添加文件上传目录常量 `UPLOAD_DIR = "upload/video"`
- 修改 `handleAddVideo` 方法，处理缩略图上传
- 修改 `handleUpdateVideo` 方法，支持保留/更新/删除缩略图
- 添加 `uploadImage` 辅助方法，处理图片文件保存

### 2. adminVideos.jsp
- 表单添加 `enctype="multipart/form-data"` 属性
- 缩略图输入从文本框改为文件上传控件
- 添加图片预览功能
- 添加现有缩略图显示和删除选项
- 修改 JavaScript 函数：
  - `openModal()`: 重置表单状态
  - `editVideo()`: 显示现有缩略图
  - `previewThumbnail()`: 预览上传的图片
  - `toggleRemoveThumbnail()`: 切换是否删除现有缩略图

## 功能特性

### 添加视频
- 支持上传图片作为缩略图
- 上传前可预览图片
- 不上传缩略图时，显示分类默认图标

### 编辑视频
- 显示现有缩略图
- 支持上传新图片替换
- 支持勾选"移除现有缩略图"来删除
- 不上传新图片且不勾选移除时，保留现有缩略图

## 文件存储
- 存储位置：`upload/video/`
- 文件名：UUID 生成，避免冲突
- 支持格式：图片文件（`accept="image/*"`）

## 使用方法

1. 点击"添加视频"
2. 填写基本信息（BV号、标题等）
3. 选择缩略图图片（可选）
4. 点击提交

编辑时：
1. 点击"编辑"
2. 可查看现有缩略图
3. 可选择上传新图片或移除现有图片
4. 点击提交
